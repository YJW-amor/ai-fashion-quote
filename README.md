# AI 服装模特图服务 · 物料

单宸（微信：单辰）的 AI 服装模特图服务对外物料，全部为可直接打开的 HTML 页面。

## 目录

| 文件 | 说明 |
| --- | --- |
| `index.html` | 物料总览首页（GitHub Pages 入口） |
| `AI服装模特图服务报价单.html` | 服务报价单：套餐分档、单价对比、交付标准、下单流程 |
| `AI模特图小程序原型.html` | 小程序交互原型：上传服装图 → 选模特 → 出成片 |
| `闲鱼9宫格素材.html` | 闲鱼推广用九宫格方图素材 |
| `单宸工作台.html` | 订单 / 素材 / 交付进度管理面板 |
| `assets/` | 页面引用的模特图、案例图 |
| `_shots/` | 本地预览截图（图内含联系方式，未纳入仓库） |
| `_backup/` | 历史版本备份 |
| `.creative-design/` | 生成与压缩预览用的辅助脚本 |
